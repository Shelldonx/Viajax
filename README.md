# Viajax — Creator Marketplace on Solana

[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org)
[![Solana](https://img.shields.io/badge/Solana-Mainnet-purple)](https://solana.com)
[![TypeScript](https://img.shields.io/badge/TypeScript-strict-blue)](https://typescriptlang.org)

> Marketplace open source para creators venderem eBooks digitais com 3% de taxa,
> pagamentos em USDC na Solana Mainnet, AI para criar conteúdo com GPT-4o,
> e checkout simples sem fricção — invisível para utilizadores, blockchain visível para developers.

## ✨ Funcionalidades
- 💳 Checkout com cartão de crédito (Crossmint → USDC automático, invisível)
- 🔗 Checkout com carteira Solana/Jupiter (Phantom, Solflare, Backpack)
- 🤖 AI Studio: PDF → análise GPT-4o → 5 templates → eBook publicado
- 💰 Payout automático em USDC para creators após 7 dias
- 📊 Taxa de apenas 3% (a mais baixa do mercado — Hotmart cobra 15-25%)
- 🌐 Open source MIT — fork, usa e contribui

## 🛠 Stack
Next.js 14 · TypeScript · MySQL · Solana Mainnet · Crossmint · Jupiter · OpenAI GPT-4o · Hostinger
